# Intellectual-Property Boundary

**Status:** Provisional; legal review required before public release

OpenBNCT is intended to be an independently written open-source research and
verification platform. It must not copy OpenPINT source code or other
reciprocal-licensed implementations. Compatibility may be implemented from
public file specifications, published methods, and independently created test
cases with appropriate attribution.

The initial public scope includes:

- DICOM and synthetic geometry handling;
- transport-backend interfaces and OpenMC integration;
- component-resolved physical dose;
- conventional, source-attributed biological models;
- visualization, DVH, comparison, benchmark, and provenance functions;
- general statistical uncertainty reporting.

The following require a recorded patent review before design, implementation,
discussion in an issue, or acceptance as a contribution:

- continuous admissible boron-map optimization;
- extremal-map construction covered by Avify Dose filings;
- designated transport-run recomposition covered by those filings;
- robust dose-bound certification or certificate-checking mechanisms;
- any other workflow that may practice an Avify Dose claim.

The project is MIT-licensed. MIT carries no express patent grant, so the
license provides no protection for patent claims necessarily infringed by a
contribution — the boundary above stands on its own, and license choice is
not a substitute for reviewing it.
